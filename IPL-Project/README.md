🏏 IPL 2022 Data Analysis Capstone Project
📌 Overview

This project explores match-level data from the Indian Premier League (IPL) 2022 season to uncover meaningful insights about team performance, match outcomes, and player contributions.

Using Python-based data analysis and visualization techniques, the project answers key questions such as:

Which team performed the best?
How important is winning the toss?
What are common winning patterns (runs vs wickets)?
Who were the standout players?
📊 Dataset Description

The dataset contains match-level information for IPL 2022, including:

date – Match date
venue – Match location
stage – Tournament stage
team1, team2 – Competing teams
toss_winner, toss_decision – Toss details
first_ings_score, second_ings_score – Scores
match_winner – Winning team
won_by, margin – Victory details
player_of_the_match – Best performer
top_scorer, highscore – Batting highlights
best_bowling, best_bowling_figure – Bowling highlights
⚙️ Technologies Used
Python
Pandas – Data manipulation
NumPy – Numerical operations
Matplotlib & Seaborn – Data visualization
🔍 Key Analysis Performed
1. Team Performance
Identified which teams won the most matches
Compared overall team success visually
2. Toss Impact
Analyzed toss decisions (bat vs field)
Measured how often toss winners also win matches
3. Winning Trends
Distribution of wins by:
Runs
Wickets
Insights into match dynamics
4. Player Performance
Top scorers and highest individual scores
Best bowling performances
Player of the Match trends
📈 Sample Insights
Certain teams dominated the season in terms of wins
Toss decisions showed noticeable strategic patterns
Winning the toss does not guarantee winning the match
Matches are often decided more by wickets than runs
